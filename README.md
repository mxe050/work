# NMA VOICEVOX 動画制作

このリポジトリは、NMA教育動画の男女2名による日本語ナレーションを、GitHub Actions上の公式VOICEVOX Engineで生成するための作業用リポジトリです。

## 制作方針

- あかり：NMAを初めて学ぶ女性役
- 佐藤：NMA・メタ解析・GRADEに詳しい男性解説役
- 音声は発話単位で生成し、話速・間・読み方を調整します。
- 大容量のWAVやMP4はGitへ直接コミットせず、GitHub ActionsのArtifactとして保存します。
- 最終音声の長さに合わせて、既存スライド動画・字幕・章立てを再調整します。

## 作業予定

1. VOICEVOXの短い男女音声サンプルを自動生成
2. 声質と話速を確認
3. v5台本を発話単位に変換
4. 全編音声を生成
5. スライド、字幕、音声を再同期してMP4を作成
